# Prime Void Hub — Storm Loader

Loader público da **Prime Void Hub — Storm Suite v1.0.0** para Roblox RSBK. O projeto Olho do Prime Void é independente.

## Execução

```lua
loadstring(game:HttpGet('https://raw.githubusercontent.com/TheIndianVoid/prime-void-hub-storm-loader/main/Loader.lua'))()
```

O arquivo `Loader.lua` consulta o gateway dedicado da Vercel, que entrega a source Luau. A source original fica no repositório GitHub privado `prime-void-hub-storm-suite`; contudo, **qualquer pessoa com acesso ao endpoint público poderá obter uma cópia do código entregue**. Um repositório privado não impede a extração de código distribuído ao cliente.

Gateway: https://prime-void-hub-storm-gateway.vercel.app/prime-void-hub.lua

Release oficial: **v1.0.0**. O loader é estável e independente do número de versão da source.
